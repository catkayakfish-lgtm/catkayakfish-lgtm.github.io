## What Are CHUNKs?

A CHUNK is one clear idea placed between two visual borders:

```
TTTTTTTTTTTTTTTTTTTTTTTTTTTTTTT 001
Your idea, question, or content goes here.
Each CHUNK has a beginning, middle, and end.
LLLLLLLLLLLLLLLLLLLLLLLLLL 001
```

**Key elements:**
- **Top border** (TTTT...) marks the start
- **Bottom border** (LLLL...) marks the end  
- **Sequence number** (001) keeps things in order
- **Content** - your actual thought or work

That's it. Simple, visual, and powerful.
